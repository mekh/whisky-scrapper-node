# 21 — the curator's own rows

Not an agent's research. This directory holds rows written by hand during
P1.10, when the golden set showed a producer the resolver could not reach:
almost always an alias the research left at `brand` scope, or a bottler range
whose name the catalogue uses and no agent aliased.

`kb-merge` scans every subdirectory of `out/`, so these merge exactly like the
agents' files and score against them by the same rule.
